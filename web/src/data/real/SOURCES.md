# Real data sources

Generated by `tools/build-data.mjs` (`npm run data`). Each module states its source and date.

| Module | Source | Licence / terms | What is kept |
|---|---|---|---|
| `motorways.js` | BASt, Automatische Zählstellen, annual results (https://www.bast.de/DE/Themen/Digitales/HF_1/Massnahmen/verkehrszaehlung/verkehrszaehlung.html) | No licence is stated on the BASt pages or the GovData entries. Shown with attribution to BASt; the project owner chose to show the stations (2026-10-13). Remove the station list if BASt objects. | Median daily traffic, truck share and lanes per segment of the Germany level; each motorway station's latest annual result (2020 or later: id, name, road, year, position, daily traffic, truck share). |
| `aachen-osm.js` | OpenStreetMap via the Overpass API | © OpenStreetMap contributors, ODbL 1.0 (https://www.openstreetmap.org/copyright) | Typical speed limit and lanes per direction of each street the Aachen model uses. |

Not yet real: population and jobs per district, the street-level vehicles, sensor masts and
their detections (no open detector feeds exist for these streets).
